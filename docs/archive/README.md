# Archivo de Documentación y Artefactos Históricos

Esta carpeta preserva conceptos previos, prototipos exploratorios, reglas y archivos de configuración de etapas anteriores del proyecto, con el fin de **no perder trazabilidad ni contexto histórico**:

- **`concepto-dos-mundos.md`**: Documento de concepto original de la fase de exploración (Septiembre 2026), antes de consolidar el portafolio en una experiencia unificada con Modo Focus.
- **`prototipos/`**: Prototipos HTML interactivos desarrollados para validar mecánicas de navegación y layouts antes de la implementación en Nuxt 4.
- **`platforms/`**: Archivos de infraestructura (`render.yaml`, `railway.json`, `vercel.json`) de pruebas previas de hosting, antes de migrar a la infraestructura definitiva en **Hostinger VPS con Coolify**.
- **`rules-diseno.md`**: Reglas de interfaz asociadas al extinto "Mundo Diseño".
- **`skills/`**: Habilidades de Claude (`revision-mundos`, `nueva-seccion`) que operaban sobre la premisa de los dos mundos.
- **`CLAUDE-legacy-dos-mundos.md`**: Versión original de `CLAUDE.md`.
- **`DEPLOY-legacy-vercel-render.md`**: Guía histórica de despliegue en Vercel + Supabase + Render.
