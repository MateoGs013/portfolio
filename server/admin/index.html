Manual del Asistente (Modo Operación)

Este panel permite a cualquier asistente o colaborador gestionar el portafolio de Mateo sin requerir conocimientos técnicos ni SQL.

1. Carga de Proyectos Hacé clic en "+ Nuevo", completá el título y el slug se generará solo. Usá las pestañas para organizar la historia, subir imágenes y agregar tecnologías.
2. Estados de Publicación LIVE: Visible en el portafolio público.
WIP: Borrador en desarrollo, no se muestra aún.
ARCHIVED: Histórico guardado pero oculto.
3. Job Hunter & CV Harvard ATS El agente Eros analiza vacantes tech automáticamente. Al seleccionar una oferta, tocá "Generar CV Harvard ATS" para previsualizar, imprimir en A4 o copiar el CV personalizado.
